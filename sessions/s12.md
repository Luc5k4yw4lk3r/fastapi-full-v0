# s12 — Conectar el frontend a la API (ENTREGABLE FINAL)

## Objetivo
Conectar el tablero vanilla JS a la API v1 real (s10), haciendo aparecer y resolver el
problema de CORS **de verdad**, y reemplazando los datos hardcodeados por `fetch`.
El tag `s12` es la **versión entregable** del proyecto: TaskFlow full-stack funcionando.

## Entra
- Servir el frontend en un **puerto distinto** al de la API (ej: `python -m http.server
  3000`) para que el error de **CORS** aparezca **de verdad** en la consola — y recién
  ahí resolverlo agregando **CORSMiddleware** en FastAPI.
- Reemplazar el array hardcodeado por **`fetch`** a la API v1 de s10 con **async/await**:
  - cargar el tablero real,
  - crear tarea vía **POST**,
  - mover de estado vía **PATCH**.
- Mantener el **estado del cliente** (lista de tareas en memoria + re-render tras cada
  operación).
- Inspeccionar cada request en la pestaña **Network** de las DevTools.
- Cierre conceptual (**sin código**): SPA vs multipágina, y dónde encajan React/Next.

## NO entra
- Frameworks.
- Build tools.
- Auth.

## Entregables
- TaskFlow **full-stack** funcionando (frontend + API + Postgres).
- Diagrama de **secuencia** del flujo completo (DOM → fetch → API → BD → render) en
  Mermaid (`docs/diagrams/`).
- Decisión de **CORS** registrada en la bitácora (`docs/trade-offs.md`).
