# s08 — Datos para agentes

## Objetivo
Sesión liviana en código: pensar los datos de TaskFlow desde la perspectiva de su
consumo (frescura y ciclo de vida), cargar datos de ejemplo realistas y diseñar un
endpoint de lectura pensado para que lo consuma un agente.

## Entra
- Documentar **frescura y ciclo de vida** de los datos de TaskFlow.
- Agregar **seeds realistas**.
- Diseñar (y opcionalmente implementar) un **endpoint de lectura pensado para consumo
  por un agente**: respuesta autocontenida, con contexto.

## NO entra
- RAG ni vectores reales.

## Entregables
- Doc de datos (frescura / ciclo de vida).
- Seeds realistas.
