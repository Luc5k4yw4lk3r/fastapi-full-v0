# s05 — Prototipo mínimo

## Objetivo
Levantar el primer prototipo de TaskFlow: una API FastAPI organizada en capas
(router → service → repository) con las entidades **Tarea** y **Proyecto** en memoria,
y dejar preparada la infraestructura de base de datos con Docker (aunque la app todavía
no se conecte a ella).

## Entra
- FastAPI en capas con entidades **Tarea** y **Proyecto** en **memoria**.
- Endpoints:
  - crear tarea,
  - listar tareas,
  - mover tarea de estado (`backlog → en progreso → hecho`).
- Cliente mínimo como script `httpx` que ejercita los endpoints.
- `docker-compose.yml` con el servicio de **PostgreSQL** + `.env.example` con
  `DATABASE_URL`.
- Verificar que la base levanta con `docker compose up -d` — **aunque la app todavía NO
  se conecta a la base**.

## NO entra
- ORM.
- Conexión a Postgres desde la app.
- Auth.
- El modelo completo de entidades (eso es s06).
- HTML / frontend.

## Entregables
- Servidor corriendo.
- Compose levantando Postgres.
- Diagrama de **componentes** (Mermaid en `docs/diagrams/`).
- Diagrama de **secuencia** del ciclo de request
  (cliente → Uvicorn → router → service → repository → respuesta).
- 3 trade-offs registrados en `docs/trade-offs.md`.
