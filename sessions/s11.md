# s11 — Frontend: del HTML al DOM

## Objetivo
Construir el tablero de TaskFlow en el navegador con **vanilla JS**, **estático y
aislado** de la API: los datos son un array hardcodeado y toda la interacción se hace
manipulando el DOM a mano. El objetivo es entender el modelo HTML → DOM → render antes
de conectar nada.

## Entra
- Crear `frontend/index.html` + `frontend/app.js` con un tablero **estático y aislado**:
  las tareas son datos **hardcodeados** en un array de JS, **sin tocar la API**.
- Todo a mano con vanilla JS:
  - generar las tarjetas manipulando el DOM (`createElement`, `appendChild`),
  - eventos de **click** para mover una tarjeta de columna,
  - un **form** con evento **submit** para crear una tarea (que vive solo en memoria del
    navegador).
- Abrir la página **directo desde el archivo**.

## NO entra
- `fetch` / conexión a la API.
- Frameworks.
- CSS elaborado.

## Entregables
- Tablero interactivo funcionando **sin backend**.
- Diagrama del flujo **HTML → DOM → render** en Mermaid (`docs/diagrams/`).
- Trade-offs en la bitácora (ej: manipular el DOM a mano vs re-renderizar todo).
